# M4-A1 internal discovery contract

Scope: the [2026-10-28 owner decision](m4_b_owner_decisions_2026-10-28.md) authorizes a fixture-only internal view model. This is not a production data adapter, student UI, recommendation engine, admission result or release approval.

`src/m4/discovery-view.ts` accepts explicitly supplied records and a marks-free all/college/profile selection. It returns a partial-coverage, source-ordered information model and a semantic next-action key. It performs no file/network access, production ingestion, ranking, cutoff/eligibility calculation or inference of current availability. Inputs require an explicit `fixture_only: true` marker; accepted source URLs use the reserved `.test` domain, and each view and item carries `SYNTHETIC_FIXTURE_ONLY`. Its review references are caller-supplied fixture strings: **they do not authenticate real approvals**. Connecting actual governed data or a student-facing renderer requires separate authorization and a real governance boundary.

Identity, each college attribute, the source-stage offering, the profile link, and bilingual profile content have independent status and provenance. A listing is excluded unless identity and offering are approved and have an identifiable source, year, recorded/verified page and offering stream/stage. An approved exact or variant link requires its own review reference. Profile wording is returned only when factual, Tamil and English review references, scoped source and both language texts are present; held, pending or absent content is never returned. A recorded page remains recorded. Missing fields remain unknown, false stays false, and conflicts retain both candidate values and references only in this internal model; no conflict candidate becomes an approved value. Duplicate source-stage pair keys are rejected.

An empty filtered result remains partial coverage and directs the caller to browse all or check an official source. Profile filtering reports how many unlinked records were excluded without implying they would have matched. Source ordering is preserved without scoring; future UI copy and actions require human review. Real source verification, admission outcomes, current vacancies, institution-specific curriculum applicability, and student usability cannot be inferred from fixture tests.
