# Official-source M4 directory candidates — review only

Prepared 2026-10-29 from the existing matrix extraction and the preserved 2026 college booklet. This is research candidate data, not production data, approval, current availability or permission for student access. The full [previous research](../research-report.md), [recorded corrections](../corrections.json), [original source manifest](../original-manifest.csv), [profile crosswalk](../code-crosswalk.csv), [profile coverage](../profile-coverage.csv) and [bounded owner decisions](../../../docs/planning/m4_b_owner_decisions_2026-10-28.md) remain unchanged.

## Candidate files

- [College candidates](college-candidates.csv): 418 string-coded college rows, consisting of all 414 matrix codes plus four booklet-only codes. Source-print and raw names are separate from the deliberately empty normalized display name. Matrix names include source address text; booklet name headers and address fields are separate. Management/institution type, autonomy and minority are independent.
- [Offering candidates](offering-candidates.csv): 3,354 distinct matrix college–programme source-stage keys, exact printed and raw names, explicit variant text where identified, source pages and extraction rows. The complete printed name is authoritative for identifying variants; a blank variant field does not establish that no other variant exists. Crosswalk entries are research leads, not associations. Every offering is NOT_APPROVED. The nine earlier bounded associations are recorded separately and do not approve the offerings.
- [Field-level provenance](field-provenance.csv): source URL, publication year, printed/PDF page, value and field status. `source_year=2026` is the publication year, not necessarily the year of the underlying fact. Seven booklet headers explicitly say previous-year data; those extracted attribute values are NEEDS_REVIEW. Blank values are UNKNOWN for use; a source dash is NOT_PUBLISHED, not a false value.
- [Exceptions](exceptions.csv) and [coverage counts](extraction-summary.json): separate booklet-only, identity conflict, district conflict, previous-year, missing and other review cases. Exception rows can overlap.
- [Preparation script](prepare_candidates.py): reads the preserved `pairs.csv` rather than re-extracting the matrix, and checks both PDF hashes before extracting booklet fields and the category-wise index. Run with `M4_CENSUS_SOURCE_DIR` pointing to the two original PDFs and Python with `pypdf`; it writes only into this review folder.

All field statuses are one of `OFFICIAL_SUPPORTED`, `NOT_CHECKED`, `NOT_PUBLISHED`, `CONFLICTING` and `NEEDS_REVIEW`. `OFFICIAL_SUPPORTED` means the indicated source text was extracted; it does **not** mean visually checked for every page, owner-approved, factually verified independently, current or display-ready. `EXTRACTED_NOT_VISUALLY_VERIFIED` is a conservative verification status even for the representative pages inspected; per-record approval remains separate. Institution type is the booklet's category-wise index label, not a derived management label or an inference from another field. `CECRI AND CIPET` is an index category and is not translated into an unsupported management type.

## Sources and accounting

The [2026 General Academic matrix before special-reservation counselling](https://static.tneaonline.org/docs/GENERAL_ACADEMIC_SEAT_MATRIX_BEFORE_SPECIAL_RESERVATION_COUNSELLING_2026.pdf) has 414 extracted college codes and 3,354 unique source-stage offerings; all appear in the candidates. The [2026 Information About Colleges](https://static.tneaonline.org/docs/Information_about_colleges_2026.pdf) has 418 parsed unique detail codes: all 414 matrix codes plus booklet-only **2332, 3555, 4911 and 4927**. A booklet-only entry does not establish a matrix offering. The PDF copies matched the preserved manifest SHA-256 values: matrix `85dbb154b56822fef150054e4508787d53b9f438fdf5a5532da7b3d02e547743`; booklet `035dd2604fa784c0ce57379783b50eca1a0972a08a6e7811ab2ca50562ce5373`.

Across all 418 booklet detail entries, automatic extraction classified 410 address, 394 district, 417 index-category, 410 autonomy, 410 minority, 410 website, 410 phone and 410 email fields as OFFICIAL_SUPPORTED. These are source-text coverage counts, not verified or approved facts. Sixteen district values conflict between explicit matrix address text and the booklet district field; both dated source values remain in provenance. The original 1303/4967 conflicts are included. College 1133 retains its identity conflict. Seven entries explicitly say previous-year data: 1102, 1221, 1510, 1516, 2350, 4943 and 5533. For 4943, eight field values are printed as dashes and classified NOT_PUBLISHED; do not infer negative facts. The previous-year entries and identity conflict can overlap other exceptions.

## Validation and limitations

The preserved matrix extraction and catalogue remain the input: no new census or broad competitor research. Check unique keys, code sets, source pages, exact raw/printed programme names and variants, field status coverage and all held codes before any downstream use. The 22 earlier spillover corrections are retained; matrix pages 105–106 were visually revisited, including the page break and corrected code cells. Booklet PDF pages 42, 54, 70, 108 and 400 were visually inspected for representative fields, the wrapped-header case, the 1133 identity conflict, the no-space `Dean/Principal` parser anomaly and the 4967 district conflict. All other page text remains machine-extracted, not exhaustively verified. Poppler reported missing display fonts during rendering; any visually ambiguous glyph requires direct source review. Code matching does not establish institutional identity, and district comparisons detect explicit district labels only; other discrepancies may remain undiscovered.

The source-stage matrix identifies recorded listings at its stated date and stage, not current availability, vacancy or admission. No seat, intake, reservation, vacancy, fee, hostel, placement or accreditation figures are exported into these candidate tables. BY/XC variant associations, AE/AO N9 and BP/DA/CQ/IF/ID/CJ scope holds remain; all other recorded catalogue holds and unresolved dispositions remain in the crosswalk/profile-coverage records. Candidate extraction does not approve profile mappings or bilingual explanation text.

**Owner-review decision:** Review supported candidate records in batches, keeping explicit identity, district, previous-year, missing-field, variant, scope and profile exceptions on hold. Each identity, attribute, source-stage offering, association and explanation needs its own decision. This review alone does not authorize an implementation, production import or student access.
