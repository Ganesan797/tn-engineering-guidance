# Approved Live LLM Review Evidence

This directory contains only owner-approved, sanitized review evidence. Raw run artifacts remain local in the Git-ignored `../../output/` directory. A manual status summary is not validation evidence.

Files enter this directory only through the explicit `approve` action documented in the parent README. The command validates the structured output again, verifies the raw-artifact SHA-256, rejects noncanonical scenario input and credential-shaped or sensitive content, and performs no Git action.
